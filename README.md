# 🛡️ AdVerify Pro: AI-Powered Market Research Agent

**AdVerify Pro** is an intelligent auditing tool designed to verify advertising quotes against live market registries. Built using **Python**, **Streamlit**, and the **LangChain** framework.

## 🚀 Key Features
* **Benchmarking:** Automated comparison against official registry rates.
* **AI Analysis:** Real-time strategic advice using LLMs.
* **Demo Mode:** Type 'DEMO' in the API key field to test without a paid key.

## 🛠️ Tech Stack
* **Frontend:** Streamlit
* **AI Framework:** LangChain (GPT-4o)
* **Data:** Pandas
