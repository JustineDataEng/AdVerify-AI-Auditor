**AdVerify Pro** is an intelligent auditing tool designed to verify advertising quotes against live market registries. Built using **Python**, **Streamlit**, and the **LangChain** framework.

## Why this project exists
As a **Data Science and Engineering Fellow** (Class of 2026), I built this to solve the problem of price transparency in local advertising. It demonstrates:
* **LLM Orchestration:** Using LangChain to analyze market data.
* **Interactive Engineering:** Deploying a real-time tool with Streamlit.
* **Security:** Professional handling of API keys for client safety.

## 🛠️ Tech Stack
* **Frontend:** Streamlit
* **AI Framework:** LangChain (GPT-4o)
* **Data:** Pandas
